1. FROM 子句必须使用上方给出的表名或占位表名，原样照抄，不要修改格式，不要使用数据集中文名。
2. SELECT / WHERE / GROUP BY 中只能使用上方列出的字段写法，原样照抄。指标字段的写法已是完整语义：有些本身就带聚合函数（如 `sum(vvuv)`、`CASE WHEN sum(a)=0 ...`），有些是裸字段（如 `vvuv`，说明数据已预先汇总好）。两种都请**原样使用**，不要给裸字段套上聚合函数，也不要把已有的聚合函数去掉。

4. **GROUP BY 规则（重要）**：仅当 SELECT 中实际使用了聚合函数（SUM/COUNT/AVG/MAX/MIN 等）时，才需要把 SELECT 里所有非聚合字段完整写入 GROUP BY，否则 SQL 会执行失败；GROUP BY 中请重复写出该字段的完整表达式，不要使用列别名或序号。若 SELECT 中没有任何聚合函数（例如指标字段本身就是裸字段），则**不要**写 GROUP BY。
